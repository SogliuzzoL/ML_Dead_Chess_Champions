# ML Dead Chess Champions


## Installation

Python 3.10.19 is used for this project, as it is incompatible with newer versions due to specific Maia-2 dependencies.

### Dependencies

To install dependencies, run:

```bash
pip install -r requirements.txt
```

### Stockfish

You should install the Stockfish model and place the executable into the `stockfish_model` folder, naming it `stockfish`. Alternatively, you can modify the Stockfish path in `src/core/config.py` by updating the `STOCKFISH_MODEL_PATH` variable.

## Project Files and Structure

### Root Configuration Files
- **`Dockerfile`** - Docker container configuration for running the project in an isolated environment
- **`docker-compose.yml`** - Docker Compose configuration for multi-container orchestration
- **`requirements.txt`** - Python dependencies required for the project
- **`README.md`** - Project documentation

### Core Source Code (`src/`)
- **`app.py`** - Flask web application for playing against Maia-2
- **`build_dataset.py`** - Script to build and prepare datasets from PGN files for model training
- **`cluster.py`** - Clustering algorithms for grouping chess players by style
- **`fetch_games.py`** - Script to fetch chess games from external chessgames.com
- **`maia.py`** - Integration with the Maia chess engine and model utilities
- **`stats_dataset.py`** - Statistical analysis and summary of chess datasets
- **`stockfish_analyse.py`** - Chess position analysis using Stockfish engine
- **`style_extractor.py`** - Extract playing style features from chess games
- **`visualize_cluster.py`** - Visualization tools for clustering results and player groupings

### Subdirectories
- **`core/`** - Core utilities and helper modules
- **`visualization/`** - Data visualization utilities and plotting functions

### Web Interface (`templates/`)
- **`index.html`** - HTML template for the web application frontend
